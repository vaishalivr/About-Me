# About Me

## Run locally

```bash
npm install
npm run dev
```

## Validation

Only run validation when explicitly requested.

```bash
npm run check
npm run build
```

This project does not require a build or validation pass after every code commit. Request a build/validation check when you want me to verify the app.

## Project structure

- `src/App.svelte`: the main landing page content and styling.
- `src/main.js`: Svelte app entry point.
- `public/`: static assets.
